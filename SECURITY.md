# Security reporting

Please report suspected ChemVault vulnerabilities or abuse privately through the [security report form](https://forms.chemvault.science/security-report). If the form is unavailable, contact [contact@chemvault.science](mailto:contact@chemvault.science).

Do not include passwords, API keys, private keys, recovery codes, tokens, malware, or data belonging to other users. Include the affected URL, safe reproduction steps, impact, timestamps and non-sensitive evidence.

ChemVault aims to acknowledge critical reports within 24 hours and high-severity reports within two business days. These are response targets, not guarantees. This repository does not offer a bug bounty, safe-harbor commitment, legal waiver, or authorization to test production systems without written approval.
