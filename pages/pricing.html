FAQ

Commercial MVP notes.

The first version is intentionally conservative: it creates the commercial contract and UI without pretending that unavailable scientific backends already exist.

Is payment live?

No. Checkout routes are placeholders until a provider such as Stripe is configured through environment variables and SDK code.

Is AI Paper Search live?

It is a beta surface with early access collection and plan-aware placeholders. It does not fabricate paper data.

Can teams use shared workspaces?

The Team/Lab plan contract exists. Shared workspace storage needs authenticated organization data before real collaboration is enabled.

How are permissions enforced?

Client gates are mirrored by server API helpers for protected actions. Real auth and subscription state should replace the placeholder plan resolver.
