Routing

Security and privacy items are handled in private admin workflows.

  • Feedback is saved to the private Forms database before any notification is attempted.
  • Submission email notifications go to forms@chemvault.science when Resend is configured.
  • Every saved submission returns a CVF ticket that can be used to view the submitted content and saved replies.
  • No feedback path creates public GitHub Issues.
