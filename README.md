# ChemVault

ChemVault is a chemistry knowledge and research-workflow product for finding scientific records, organizing research material, exploring molecular structures, and moving between connected laboratory tools.

## Website

The ChemVault website provides a public chemistry knowledge layer and the main entry point to the ChemVault product suite.

### Chemistry search and records

- Search compounds, reagents, reactions, mechanisms, materials, methods, dossiers, literature, and source records.
- Filter results by record type, scientific domain, topic, and research intent.
- Open structured record pages with identifiers, summaries, linked context, credibility notes, safety guidance, and research-oriented next steps.
- Browse dedicated reagent, materials, mechanism, spectroscopy, methods, reproducibility, academic-library, and research-dossier surfaces.
- Use stable public record pages and a multilingual public record index for reference and sharing.

### Research and product workspaces

- Move between Compound Search, File Library, Lab, Molecule Studio, Mail, Notifications, Forms, Downloads, User Center, and Documentation.
- Review public research directions, platform capabilities, publications, project notes, team information, and contact options.
- Submit support, feedback, early-access, newsletter, and enterprise enquiries through tracked website forms.
- Access account, plan, billing-management, and data-request entry points through ChemVault User Center.

### Plans and cloud services

- Free access covers the public knowledge site, basic connected-app entry points, and local-first Molecule Studio capabilities.
- Pro adds paid cloud services such as higher storage and analysis allowances, mail capacity, and optional metered cloud quantum calculation.
- Team/Lab remains an approved-pilot offering while organization membership, seat provisioning, and shared-resource controls are completed.
- Enterprise/Institution access is reviewed around capacity, procurement, support, data boundaries, and integration requirements.

Public checkout remains disabled until the production billing, legal, tax, support, and cross-service canaries are approved. Plan descriptions therefore represent the intended controlled service boundary rather than an invitation to make a live purchase today.

## Molecule Studio

ChemVault Model provides molecule search, 2D input, structure-file import, property inspection, 3D visualization, and local export. The Windows application adds local or user-licensed Gaussian, ORCA, PySCF, and xTB workflows with preflight checks, progress, cancellation, project history, result comparison, and report exports.

Local engines use the user's own computer and do not consume ChemVault cloud quota. Optional ChemVault-hosted quantum calculation is a separate Pro-or-higher service with a centrally enforced daily allowance.

## Apple App

The native ChemVault Apple app supports iPhone, iPad, and Mac without using a WebView shell.

- Search compounds by name, synonym, formula, identifier, or SMILES.
- Use the built-in compound index when live enrichment is unavailable.
- Review formula, domain, type, summaries, tags, and record links.
- Open connected Files, Documentation, Lab, Mail, Notifications, account, and settings surfaces.
- Use English or Simplified Chinese with automatic region selection and manual language control.

## Availability

ChemVault is in controlled beta. Public knowledge pages and explicitly marked local tools are available now; paid cloud services, Team collaboration, platform distribution, and provider-backed operations are enabled only after their documented release gates pass.
