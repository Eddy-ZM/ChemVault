# TestFlight Review Checklist

Draft only. Needs Apple review and legal review.

- [ ] Privacy Policy URL resolves publicly.
- [ ] Support URL or support contact resolves publicly.
- [ ] Beta description states the build is unstable/incomplete.
- [ ] What to Test does not ask users to upload sensitive real data.
- [ ] AI/scientific extraction outputs are described as requiring human review.
- [ ] Account deletion request entry exists and is reachable.
- [ ] Sign in with Apple is reviewed against third-party login options.
- [ ] App Privacy Details draft is updated from exact binary behavior.
- [ ] No private keys, API keys, or provisioning files are included in the app bundle.
- [ ] Reviewer notes include test account instructions only when safe.
- [ ] Email, file upload, AI processing, and user-generated content risks are disclosed.

No checklist item guarantees App Store approval.
